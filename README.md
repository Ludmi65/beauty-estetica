Beauty Estética ~ Realza tu belleza natural ~
Beauty Estética es un sitio web que fue diseñado para publicitar un salón de belleza y cuidado personal, 
con diferentes servicios, donde muestra su identidad y contacto para solicitar turno.
Los servicios incluyen: manicuría, maquillaje, tratamientos capilares, extensiones de pestañas.
Utilicé tres estructuras HTML (inicio,nosotros,contacto). Mediante el css le di estilo a la página y la adaptación para celulares.
Mientras que con Java Script le di funcionalidad al formulario para solicitar turnos(valida los datos y confirma), 
y logré interactividad con las ventanas emergentes en  inicio.
